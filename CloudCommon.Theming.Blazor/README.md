# CloudCommon.Theming.Blazor

Optional Blazor scope for CloudCommon.Theming. Wrap UI in CloudThemeScope with Theme, Mode, optional Class, Nonce and ChildContent. Import AngryMonkey.CloudCommon.Theming and AngryMonkey.CloudCommon.Theming.Blazor. Scopes are independent and render styles during server rendering; Nonce supports CSP hosts.

Use CloudThemeDocument in the document head to configure :root. Set data-amc-theme on html to light, dark or system. Supports Blazor Server and WebAssembly. A generated standalone stylesheet is available at _content/AngryMonkey.CloudCommon.Theming.Blazor/css/theme.css.

Package ID: AngryMonkey.CloudCommon.Theming.Blazor. Requires .NET 10. Version 0.1.0 is currently built locally and has not been published.
