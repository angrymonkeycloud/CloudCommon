# CloudCommon.Theming

Dependency-free theme configuration, palette generation, semantic tokens, element states, visual overrides, scoped animations and portable CSS export. Start with CloudThemes.Color("#6750a4") or CloudThemes.Grayscale(), then call ThemeCss.Export(theme). Apply the exported cloud-theme class and data-cloud-element targets in any framework.

Package ID: AngryMonkey.CloudCommon.Theming. Requires .NET 10. Version 0.1.0 is currently built locally and has not been published.
