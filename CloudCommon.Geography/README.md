# CloudCommon.Geography

Explicit compatibility adapters between CloudCommon.Models and existing CloudGeography Money/Coordinate. Import AngryMonkey.CloudCommon.Geography, then call ToCommon() or ToGeography(). Empty legacy money maps to null. The core common models remain independent of geographic datasets.

Package ID: AngryMonkey.CloudCommon.Geography. Requires .NET 10. Version 0.1.0 is currently built locally and has not been published.

CloudCommon is part of Angry Monkey Cloud. Follow the [shared AI instructions](https://github.com/angrymonkeycloud/CloudDocs/blob/main/docs/ai/instructions.md). Visit [Angry Monkey Cloud](https://angrymonkeycloud.com) and the [GitHub organization](https://github.com/angrymonkeycloud).
